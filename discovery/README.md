# Discovery

The motion to find more — everything here goes beyond what the brief handed us, or pressure-tests it. Structured after the `genai-poc-strategy` skill's Align phase (`.claude/skills/genai-poc-strategy/1-align-guide.md`), plus one repo-specific document that answers the brief's hardest ask directly.

| File | What it is |
|------|-----------|
| `align/pain-points.md` | The pain-point inventory — mostly `hypothesis — validate` pre-kickoff |
| `align/discovery-notes.md` | Synthesized themes about *why* the pain is invisible to the team itself |
| `align/discovery-questions.md` | The actual question bank for tomorrow's kickoff call |
| `align/value-charter.md` | Engagement intent, value levers, and success criteria — becomes the scoring lens for any later Assess work |
| `discovery-session-design.md` | How to design a discovery session that creates a "this is actually relevant to me" moment — the brief's core ask |

Every claim here is either cited to `case-file/scenario-brief.pdf` or explicitly labeled `hypothesis — validate`. Once the real kickoff call happens, replace hypotheses with what was actually said.
