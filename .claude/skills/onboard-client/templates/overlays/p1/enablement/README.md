# Enablement

The P1 Claude Activation workstream: getting the client's team using Claude on its real work, and measuring whether it sticks.

| File | What it is |
|------|-----------|
| `use-case-backlog.md` | Candidate use cases by team and persona, from candidate to adopted |
| `session-plan.md` | Every workshop, office hours, and training the SOW commits to |
| `champions.md` | Who carries adoption inside the client once Caylent steps back |
| `adoption-baseline.md` | Where usage stood before enablement, and how movement is measured |
| `kit/` | Working versions of the Skills, Project instructions, and prompt kits we're building |

**Flow:** a use case moves from `use-case-backlog.md` into a session in `session-plan.md`, gets an asset in `kit/`, and is tracked in `adoption-baseline.md`. When an asset is finished and handed over, its final version moves to `deliverables/` and the tracker row is updated.
