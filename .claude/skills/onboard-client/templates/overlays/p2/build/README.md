# Build

The P2 agentic-workflow workstream: the product thinking behind what gets built. Specs, integrations, decisions, and evals live here. **Code lives in the repo named in `context/engagement-profile.md`**, not here, unless the profile says otherwise.

| File | What it is |
|------|-----------|
| `workflow-inventory.md` | Each target workflow: how it runs today, what it should become, where people stay in the loop |
| `integrations.md` | Systems and connectors, access status, and environments |
| `decisions.md` | Decision log: what was decided, why, and what else was considered |
| `evals.md` | How we'll know it works, and who signs off |

Plan the build with `/task-planning`. The plan goes in `.ai/tasks/`, and `/step-execution` runs it.
