# Task plans

Planning documents for multi-step initiatives in this engagement, produced by `/task-planning` and executed with `/step-execution` or `/step-loop`.

## Layout

```
.ai/tasks/YYYY-MM-DD/<slug>/
├── <slug>-context.md        # objective, scope, requirements, risks (source of truth)
├── <slug>-steps-guide.md    # step index, dependency rules, status
└── <slug>-steps-1-5.md      # up to 5 steps per doc; the last step is always validation
```

Use a plan when the work won't fit in one session: a P2 workflow build, a multi-week enablement program, a deliverable with several dependent parts. Small tasks don't need one.
